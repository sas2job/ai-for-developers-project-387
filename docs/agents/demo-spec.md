# Явно показать часовой пояс гостю

Статус: согласовано пользователем 13 ноября 2026 года в диалоге: «Да», «Подтверждаю план и проверки». Входящее обращение: https://github.com/sas2job/ai-for-developers-project-387/issues/4.

## Problem Statement

Гость выбирает свободное время для звонка и должен понимать, в каком часовом поясе показаны часы. Календарь уже рассчитывает доступность по Europe/Moscow, но интерфейс не объясняет это рядом с выбором времени.

## Solution

Показать рядом с календарём выбранного типа встречи постоянную подпись «Время по Москве (Europe/Moscow)». Сохранить существующие даты, свободные слоты и поведение записи.

## User Stories

1. Как гость, я хочу видеть часовой пояс перед выбором времени, чтобы правильно спланировать звонок.
2. Как гость, я хочу видеть одну и ту же подпись при смене даты, чтобы не сомневаться в значении часов.
3. Как гость, я хочу сохранить текущий путь записи, чтобы новое пояснение не мешало бронированию.
4. Как владелец календаря, я хочу использовать уже согласованный часовой пояс, чтобы не менять расписание.
5. Как наставник, я хочу увидеть согласование плана, реализацию, тесты и независимое ревью в GitHub.

## Implementation Decisions

- Использовать уже согласованный часовой пояс календаря и терминологию словаря.
- Пояснение показывается на экране выбранного типа встречи рядом с датами и временем.
- Формат API, правила доступности, хранение записей и публичные маршруты сохраняются.
- Один вертикальный тикет объединяет пояснение в интерфейсе и проверки поведения.
- Изменение проходит в отдельной ветке и pull request. Решение о мерже принимает человек.

## Testing Decisions

- Проверить публичный HTTP-ответ страницы выбора времени: подпись видна вместе с календарём.
- Проверить браузерный гостевой сценарий: гость видит пояснение и успешно создаёт запись.
- Использовать существующие Rails integration tests и Selenium system tests. Новые тестовые интерфейсы не нужны.
- Полный набор проверок приложения должен остаться зелёным.

## Out of Scope

Выбор другого часового пояса, перевод времени в часовой пояс браузера, изменение рабочего графика и новые API-маршруты.

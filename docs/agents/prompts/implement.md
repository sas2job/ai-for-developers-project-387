# Реализация

Прочитайте AGENTS.md, GLOSSARY.md, относящиеся ADR и инструкции `docs/agents/skills/implement-spec/SKILL.md`, `docs/agents/skills/tdd/SKILL.md`.

`context.json` содержит согласованный запрос и ссылки на утверждённые спецификацию и тикеты. Сначала прочитайте их. Используйте одну интеграционную ветку, свежий контекст исполнителя для каждого готового тикета и отдельное ревью. Держите изменения в согласованных границах.

Не меняйте workflow, инструкции агентов, обработчики автоматизации, Git-конфигурацию или команды обязательных проверок. Проверяйте внешнее поведение приложения существующими тестами. Выполните подходящие проверки и запишите их фактический результат.

Подготовьте текстовый patch и JSON по схеме `change.json` с описанием поведения, проверок и риска. Не используйте учётные данные, не пушьте ветку, не создавайте PR и не делайте merge: результат публикует отдельный доверенный обработчик, а решение о мерже принимает человек.

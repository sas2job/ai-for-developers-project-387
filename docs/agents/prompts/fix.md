# Доработка по ревью

Прочитайте AGENTS.md, GLOSSARY.md, связанные ADR, согласованную спецификацию и тикеты. Из `context.json` изучите discussion, reviews и inline: в них сохранены общие замечания и комментарии к строкам diff.

Используйте текущий head и ту же контролируемую ветку PR. Исправьте подтверждённые замечания по скиллу `docs/agents/skills/tdd/SKILL.md`; для неприменимых замечаний дайте обоснование. Сохраните согласованный объём, права и обязательные проверки.

Верните текстовый patch и JSON по `change.json`, перечислите исправления, проверки и риск. Не создавайте другую ветку или PR, не меняйте автоматизацию и не делайте merge. Доверенный обработчик отклонит устаревший head или несогласованное изменение.
